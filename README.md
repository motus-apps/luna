# Luna

Kleine Web-App, die zeigt, wo man gerade im Zyklus steht: Zyklustag, Phase, fruchtbares Fenster, Hochphase, emotionale Tage und die nächsten Perioden.

- Mehrere Personen mit Name und Emoji
- Benachrichtigungen für emotionale Tage, fruchtbare Tage, Hochphase und Periode (als installierte App unter Android/Chrome auch im Hintergrund)
- Export der nächsten Zyklen als Kalendertermine mit Erinnerung (.ics), optional mit neutralen Titeln
- Alle Daten bleiben lokal im Browser – kein Konto, kein Server, kein Tracking
- Als App installierbar (PWA) und offline nutzbar, Backup als Text

Die Prognosen beruhen auf Durchschnittswerten und sind keine medizinische Auskunft und keine Verhütungsmethode.
