# Luna

Kleine Web-App, die zeigt, wo man gerade im Zyklus steht: Zyklustag, Phase, fruchtbares Fenster und die nächsten Perioden.

- Alle Daten bleiben lokal im Browser (localStorage) – kein Konto, kein Server, kein Tracking
- Als App installierbar (PWA) und offline nutzbar
- Backup als Text zum Kopieren und Wiederherstellen

Die Prognosen beruhen auf Durchschnittswerten und sind keine medizinische Auskunft und keine Verhütungsmethode.
